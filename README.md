# 📍 Serralheria Precisão Metal - Campinas

Este é o website institucional e plataforma de atração de clientes da **Serralheria Precisão Metal**, com sede em Campinas - SP. O projeto foi desenvolvido com foco absoluto em **SEO Local (Search Engine Optimization)** para dominar as buscas orgânicas de serralheria na região de Campinas e cidades vizinhas.

---

## 🚀 Status do Projeto
**Status:** `Pronto para Produção` (Ready for Deploy)

O projeto foi validado localmente, compilando sem erros e gerando com sucesso os arquivos de otimização de busca (Sitemaps) e arquivos para publicação em servidores de borda.

---

## 🛠️ Tecnologias Utilizadas

O ecossistema técnico do projeto foi escolhido para aliar velocidade máxima de carregamento a facilidade de manutenção de conteúdo estruturado:

1. **[Astro (v4.15+)](https://astro.build/):** Framework web moderno focado em performance, que compila o site de forma híbrida ou estática por padrão, garantindo nota máxima em velocidade no Google PageSpeed (Core Web Vitals).
2. **[Tailwind CSS](https://tailwindcss.com/):** Framework de estilização utilitário para design responsivo, mantendo a consistência visual em dispositivos móveis e desktops.
3. **[Astro Sitemap Integration](https://docs.astro.build/pt-br/guides/integrations-guide/sitemap/):** Geração dinâmica do arquivo `sitemap-index.xml` a cada build de produção.
4. **[Astro Vercel Adapter](https://docs.astro.build/pt-br/guides/integrations-guide/vercel/):** Adaptador oficial para implantação rápida na plataforma de computação serverless da Vercel.
5. **[JSON-LD & Schema.org](https://schema.org/):** Dados estruturados semânticos específicos para negócios locais (`LocalBusiness` e `HomeAndConstructionBusiness`), facilitando o ranqueamento no Google Maps.

## 📈 Estratégia de SEO Local (Diferencial Técnico)

*   **Páginas Dinâmicas de Serviços:** 9 landing pages criadas a partir de coleções de conteúdo (`Content Collections`) focando em serviços específicos (Mezaninos, Portões, Estruturas Metálicas, etc.).
*   **Campanha de SEO por Bairros:** Páginas personalizadas para mais de 15 bairros estratégicos de Campinas (Cambuí, Ouro Verde, Taquaral, etc.) com depoimentos e FAQs individualizados para evitar punições do Google por conteúdo duplicado.
*   **robots.txt & Sitemaps:** Integração completa para instruir os robôs de busca.
*   **Geolocalização:** Metatags geoespaciais (`geo.region`, `geo.placename`, `geo.position`) e coordenadas integradas no JSON-LD de Local Business.

## 📦 Como rodar localmente

### 1. Instalar dependências
```bash
npm install
```

### 2. Rodar servidor de desenvolvimento
```bash
npm run dev
```
O servidor estará acessível em: `http://localhost:4321/`

### 3. Compilar para Produção (Build)
```bash
npm run build
```
